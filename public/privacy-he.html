מדיניות פרטיות

עודכן לאחרונה: 17 בנובמבר 2026 · English

FitForge ("אנחנו", "האפליקציה") היא אפליקציה לתכנון אימונים שזמינה בכתובת fitforge-app-rygc.onrender.com. מדיניות זו מסבירה איזה מידע אנחנו אוספים, למה, ומה האפשרויות שלכם.

המידע שאנחנו אוספים

  • פרטי חשבון: כתובת האימייל ושם התצוגה. בהרשמה עם אימייל, הסיסמה נשמרת רק כגיבוב (hash) חד־כיווני מאובטח. בהתחברות עם Google אנחנו מקבלים מ־Google את השם, כתובת האימייל ומזהה החשבון. איננו מקבלים את סיסמת Google שלכם.
  • נתוני האימון שלכם: תוכניות האימון שאתם יוצרים (תרגילים, סטים, חזרות, זמני מנוחה, משקלים, חימום ומתיחות) והאימונים שהשלמתם (תאריך, משך, סטים שבוצעו).
  • הפרופיל שלכם (אופציונלי): אם תמלאו את "עליכם", נשמור את התשובות (מטרה, ניסיון, מקום האימון, טווח גיל, רמת פעילות, ימים וזמן פנויים, דברים להימנע מהם), ובאופן אופציונלי את הגובה ויומן משקל הגוף. המידע משמש רק להתאמת ההצעות של עוזר התוכניות ולהצגת גרף המשקל שלכם. הוא פרטי: לא מוצג למשתמשים אחרים או למנהל האפליקציה (שרואה רק כמה משתמשים מילאו פרופיל). אפשר לשנות או למחוק אותו בכל עת מתפריט החשבון.
  • תוכניות משותפות (אופציונלי): אם תבחרו לשתף תוכנית, השם, הקטגוריה והתרגילים שלה יוצגו לכל משתמשי FitForge יחד עם שם התצוגה שלכם. אנחנו גם סופרים כמה משתמשים צפו בכל תוכנית משותפת והוסיפו אותה. אפשר להפסיק לשתף בכל עת.
  • משוב: אם תשלחו משוב, נשמור את ההודעה, סוגה, דירוג אופציונלי, המסך שבו הייתם וסוג המכשיר והדפדפן. מנהל האפליקציה יכול לקרוא אותו, יחד עם שם החשבון והאימייל שלכם, כדי להשיב ולשפר את האפליקציה.
  • מידע שימוש: אירועי פעילות בסיסיים כמו התחברויות, פתיחות של האפליקציה ותחילה, סיום או יציאה מוקדמת מאימון, עם זמנים. אנחנו משתמשים בהם כדי להציג לכם סטטיסטיקות ולהבין את השימוש באפליקציה באופן כללי.
  • מידע טכני: ספק האחסון שלנו עשוי לרשום מידע בקשה רגיל (כמו כתובת IP וסוג דפדפן) לצורכי אבטחה ואמינות.

איך אנחנו משתמשים במידע

  • כדי ליצור ולאבטח את החשבון ולשמור על ההתחברות.
  • כדי לשמור את התוכניות והאימונים ולסנכרן אותם בין המכשירים.
  • כדי להציג השוואות אימון (הזמן הקודם, ממוצע שבועי וחודשי).
  • כדי להציג תוכניות שבחרתם לשתף, עם מספרי הצפיות וההוספות.
  • כדי להפעיל, לתחזק ולשפר את האפליקציה, כולל סטטיסטיקות שימוש מצטברות שמנהל האפליקציה רואה.

איננו מוכרים את המידע האישי שלכם ואיננו משתמשים בו לפרסום.

נתוני משתמש מ־Google

כשאתם בוחרים "המשך עם Google", ‏FitForge מבקשת רק את ההרשאות הבסיסיות לפרופיל (openid, email, profile). המידע משמש רק לחיבור לחשבון ולזיהוי שלו, ואינו משותף עם צדדים שלישיים ואינו משמש לשום מטרה אחרת. השימוש של FitForge במידע שמתקבל מממשקי Google עומד ב־Google API Services User Data Policy, כולל דרישות השימוש המוגבל (Limited Use).

איפה המידע נשמר ומי רואה אותו

המידע נשמר במסד נתונים שמאוחסן אצל Render ‏(render.com) באיחוד האירופי (פרנקפורט). מנהל האפליקציה יכול לראות פרטי חשבון וסטטיסטיקות שימוש (כמו מספר התוכניות והאימונים) כדי להפעיל את השירות. אנחנו משתפים מידע עם ספקי שירות רק כשצריך כדי להפעיל את האפליקציה (אחסון, ושליחת אימיילים אם תופעל), או כשהחוק מחייב.

שמירה ומחיקה

אנחנו שומרים את המידע כל עוד החשבון קיים. אפשר למחוק את החשבון ואת כל המידע הקשור אליו בכל עת מתוך האפליקציה (הקישו על האות הראשונה של שמכם במסך הבית ← מחיקת החשבון שלי), או בפנייה באימייל. המחיקה היא לצמיתות.

אבטחה

החיבורים מוצפנים ב־HTTPS, הסיסמאות שמורות כגיבוב, והגישה למסד הנתונים מוגבלת. אף שיטת אחסון אינה בטוחה ב־100%, אבל אנחנו נוקטים צעדים סבירים כדי להגן על המידע.
